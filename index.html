Getting a new WiFi card for my HomeLab PC

Today, I got my old Lenovo laptop and took the Intel Dual Band Wireless-AC 3165NGW WiFi card out of it.

Luckily, my Dell OptiPlex has an M.2 slot that works with WiFi cards, so I could replace my external USB WiFi receiver with an M.2 one instead.

It works, and I'm happy!

Yes, I'm using WiFi right now. The main reason is that I can't run a 20-meter Ethernet cable through my home. So, as long as the PC stays on my desk for learning purposes, I'll use the WiFi card.

Thinking about replacing my old Home Server

I've been thinking about simplifying my HomeLab setup. My current home server is quite big and consumes more space and power than I'd like.

Instead of keeping a large server running 24/7, I'm considering moving my storage to an Icy Box with two HDDs and using my Dell OptiPlex Micro as the main machine for Docker and other services.

This setup would be smaller, quieter and probably much more power-efficient.

I haven't made the final decision yet, but the idea of replacing one big server with a small DAS and a Mini PC sounds cool.
